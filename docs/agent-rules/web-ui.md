# Web と UI

- [既存構成](../../apps/web/README.md) と指定された画面を確認する。Vite、TanStack Router / Query、Base UI の実装を使い、他プロジェクトの Next.js・nuqs・Radix 前提を持ち込まない。
- ページ専用の部品・query・テスト・stories はページの隣に置く。複数ページで実際に共有するときだけ `features` / `components` へ移す。
- 共有・再読み込み・戻る操作で復元すべきフィルター、選択、入力シートの開閉は既存の search schema に合わせる。会話本文、写真、編集中の入力は URL に入れない。遷移で未保存の編集を失わないか確認する。
- 既存の共通 UI とテーマ変数を使い、ライト・ダーク、狭い画面、キーボード操作、フォーカス、ラベルを確認する。表示と操作は対象利用者に必要な情報に絞る。
- 読み込み中・空・失敗・保存中など、対象処理に存在する状態を stories で再現する。共通 UI の隣には story を置く。架空の異常状態を増やさない。
- Storybook は MSW の架空応答を使う。画面の見た目と操作を確認した後、API をまたぐ変更はローカルアプリでも入力から保存・再表示まで確かめる。指定された実データ・実機の確認とは区別する。
