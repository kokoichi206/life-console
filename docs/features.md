# 機能と操作

## やること

『やること』で仕事・私生活のタスクと買い物を管理します。仕事画面のタスクと同じ記録を使い、完了状態や編集内容を共有します。

- タスクは内容だけで追加でき、実施日時・期日・参照リンク・メモは任意。指定時刻の作業と、終える期限を別に記録
- 買い物は場所を一度登録し、その場所の欄で品名だけを入力して追加
- 同じ品を複数の場所に紐づけ可能。『登録済みの品をここにも追加』か、編集内の場所ボタンで変更
- スマホは行の右スワイプ、PC は『購入済みにする』ボタンで購入状態を変更。購入済みはすべての場所の未購入一覧から外れ、『元に戻す』または『完了済みを見る』から取り消し可能
- 場所の名前、品名を編集でき、場所の紐づけをすべて外した品は『場所なし』に表示。品の編集欄は場所をまたいで 1 つに共有

実施日時の登録による自動実行・通知は行いません。外部操作は既存の仕事画面で明示的に起動します。

## 仕事

Slack・Chatwork・Gmail・Talknote の連絡を集め、返信や作業が必要なものを整理します。会話から返信案を作り、タスクにしたものは作業リポジトリと紐づけて Codex / Claude Code へ渡せます。

- 返信案は会話履歴と本人の返信状況を踏まえて生成。Gmail と同じアカウントのメインカレンダーから日程候補を提案
- 下書きは本人が確認・編集。Slack / Chatwork はアプリから送信でき、Gmail / Talknote はコピーして元のサービスで送信
- coding agent は Orca 経由で既存の checkout または新しい worktree に起動
- agent が本人の判断を必要としたらホームの『あなたの確認待ち』へ質問。回答・修正指示を保存すると同じ agent が受け取って作業を継続
- GitHub で追跡したいタスクは Issue・非公開 Project へ昇格
- PR・Issue のレビュー・判断・マージ確認は『自分の確認待ち』に表示。理由・推奨案・確認済み／未確認の根拠を見て GitHub へ進み、対応済みを記録。[Orca からの取り込み仕様](work-confirmations.md)

タスクの管理元は Life Console。GitHub への昇格は一方向で、agent の作業環境は Mac に残ります。

## 健康と家計

| 対象 | 記録・振り返り |
| --- | --- |
| 体重 | 体重（30〜110 kg）と任意の体脂肪率（5〜40 %）を記録。実測値と 7 日移動平均、目標への進捗。グラフには週の消費カロリー・走行距離・体脂肪率を切り替えて追加表示し、選択中のボタンを再度押すと解除。Obsidian への書き出し |
| 運動 | [Strava の本人用連携](strava-integration.md)。週の走行距離・回数・時間を体重・食事と同じ期間で振り返る。運動名・距離・時間・心拍数・消費カロリーを定期同期で保存し、運動一覧と日別収支は DB から表示する |
| 食事 | 写真とメモ、任意のカロリー入力による記録。未入力なら runner で推定し、食事ごとと日別の合計を表示 |
| 禁欲 | ホームで継続中の経過時間と、中断まで継続できた時間を確認。中断履歴と任意のメモを記録 |
| 家計 | 月ごとの収支、カテゴリ別・支払手段別の支出、資産配分と純資産の推移。手入力と CSV 取り込み |

禁欲の開始日時と中断日時は秒まで保存します。中断履歴の継続時間は日・時間・分で表示し、1 分未満は切り捨てます。現在の継続時間は秒まで表示します。中断の入力欄は開いた時点の日時で初期化します。禁欲の中断履歴は直近 3 件を表示し、過去分は『過去の中断を表示』から 20 件ずつ追加表示します。閉じて開き直すと過去 20 件の表示に戻ります。メモは押すと開閉し、メモなしの行には背景の帯を付けません。各中断の継続時間は前回の中断から、最初の中断は現在の目標の開始日時から計算します。開始日時より前の記録には継続時間を表示せず、その旨を示します。

健康ページは、リンクを知っている人に読み取り専用で共有できます。本人画面の『共有リンク』で現在の表示条件を渡し、受け取った人も期間・表示条件を変更できます。記録・編集・同期・解析のボタンは非活性になります。[共有の設定と停止方法](operations.md#健康ページの共有)を参照してください。

スマホのホーム画面に追加して使えます。Android には体重・食事の入力を直接開くウィジェットもあります。

## 連絡の定期実行

『同期・実行状況』の『連絡の定期実行』で、Gmail・Slack・Chatwork・Talknote の未設定・有効・停止中、次回実行、直近の同期結果を確認できます。1 時間・2 時間・1 日・1 週間ごとの登録、頻度変更、一時停止・再開、今すぐ同期に対応します。初回を登録直後に実行するかも選べます。取得元と範囲は Mac の既存設定を使い、返信送信や agent 起動は予約しません。
